# WALMART DATA ENGINEERING PROJECT

* \## Project Description



* This project implements an end-to-end data engineering pipeline for processing and transforming Walmart retail data using modern data engineering technologies. The pipeline demonstrates data ingestion, cloud-based storage, data transformation, data modeling, data quality validation, and workflow orchestration.



* The project uses \*\*AWS S3\*\* as the cloud storage layer, \*\*Databricks and Apache Spark\*\* for scalable data processing, \*\*dbt\*\* for SQL-based data transformation and modeling, and \*\*Apache Airflow\*\* for pipeline orchestration. The workflow is designed to move data through different processing stages and produce structured, analytics-ready datasets.



* This project was developed as a hands-on learning and portfolio project based on a data engineering tutorial, with the goal of gaining practical experience with cloud data platforms, ETL pipelines, data transformation, orchestration, and modern data engineering workflows.
